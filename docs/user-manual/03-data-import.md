### 3.2 操作步骤

1. 点击右上角 **📂 打开数据文件**，选择 `tests/data/injection_process.xlsx`
2. 上传成功后，左侧出现 44 个列名，每列旁有 **类 / X / Y** 三个勾选框
3. 点击 **智能识别** 按钮自动标记：
   - Y（目标列）：含"不良/强度/伸长/冲击/粗糙/偏差/波动/效率"的列
   - X（因子列）：数值型且非类别列
   - 类别：含"日期/班次/车间/原料/类型/批号"等关键词或文本型列
4. 手动调整标记（勾选/取消勾选）
5. 点分析按钮

> **提示**: 不需要全选所有列。选择 3-8 个相关因子列即可，选太多会让结果表格过大。

> **文件编码（仅 CSV）**：“打开数据文件”按钮右侧的“自动识别”下拉框可显式指定文件编码。
> UTF-16/UTF-32 文件**带 BOM** 时自动识别即可正确读取；**无 BOM 的 UTF-16 请手动选择UTF-16**
> ——这种文件在自动模式下**可能**被当成 GBK 读成乱码且不报错（也可能直接报错，取决于字节内容，
> 2026-09-21 实测 6 个样本中 5 个安全报错、1 个静默乱码）。
> **繁体 Big5 文件请手动选“Big5（繁体）”**——Big5 与 GBK 字节范围重叠，自动模式会按 GBK 读成乱码且不报错。
> 切换下拉框会立即用同一文件重新上传。

> ⚠️ **.xlsm 宏文件提醒**：SmartSuite 读取 .xlsm 时只解析单元格数据，**不执行也不保留 VBA 宏**；
> 工具不会修改你的源文件（只读打开），因此宏不会被剥离也不会被运行。
> 如需保留宏并继续用 Excel 编辑，请在 Excel 中操作后用本工具分析导出的数据副本。
> 另请确认宏来源可信：本工具不做宏安全审查。
