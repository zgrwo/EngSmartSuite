### 按钮说明

| 按钮 | 功能 |
|------|------|
| **📂 打开数据文件** | 上传 .xlsx / .xlsm / .csv 文件（最大 50MB） |
| **智能识别** | 自动根据列名推断 Y/X/类别（含"不良/强度"→Y，"日期/车间"→类别） |
| **全选Y / 全选X** | 批量将数值列标记为 Y 或 X |
| **清空** | 清除所有列标记 |
| **分析按钮** | 绿色/蓝色/橙色/粉色/紫色分组按钮，点击运行对应分析 |
