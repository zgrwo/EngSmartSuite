## 2. 合规性结论（项目红线）

### ✅ 全绿项（实机验证）

1. **架构分层**：engine/core 全量 import 扫描零 flask/xlwings 依赖；web/cli 零 engine 直接导入；services/orchestrator 为唯一桥接。
2. **注册清单一致性**：TASK_REGISTRY = api-reference.md = TASK_LABELS = TASK_PARAMS(app.js) = YAML 模板 = **41 完全匹配**，无孤儿、无重复。
3. **签名一致性**：47 个函数（41 公开 + 6 内部）均遵循 `(AnalysisRequest) -> AnalysisResult` 统一契约。
4. **无裸 except**：53 处 `except Exception:` 全部有 `logger.exception()`/`exc_info=True` 或返回错误值。
5. **PALETTE 键律**：已知 bug（`PALETTE["anomaly"]["secondary"]`）已从代码中清除。
6. **测试 4 层防线**：① 数值正确性 40/41 ② 数学不变量 ~16/41 ③ 边界 41 任务全循环 ④ CLI/Web 差分 41/41。
7. **上传安全**：路径遍历不可利用（服务端生成路径）、zip-bomb 守卫（200MB/1000 条目）、CSRF 常量时间比较、HttpOnly+SameSite+CSP+nosniff。
